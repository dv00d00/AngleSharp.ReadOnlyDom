Hacker News, one row at a time

The server folds the list page into one JSON line per story and flushes each line the moment that story's markup is final, so rows appear as the bytes arrive. Scroll, and each row unfurls the same way a chat client does: the linked page's card metadata streams in field by field, and the fetch is abandoned as soon as the head ends.

Loading the front page …

    Cards load as rows scroll into view, three requests at a time, and the server stops reading each page the moment its <head> ends—so a card usually costs a few kilobytes of a page that weighs hundreds. Feeds come from a 15-second snapshot and cards from a 10-minute one, so scrolling back up costs nothing. Remote text is only ever added as text, never as markup, and remote images are re-served through this origin, so a preview never dials a third party from the browser.
